# yohangwak/tap

Homebrew casks for [Slash Command](https://github.com/yohangwak/slash-command).

```sh
brew install --cask yohangwak/tap/slash-command
```

This installs the app into your Applications folder and links its command line tool as `slashcommand`.

To remove it: `brew uninstall --cask slash-command`. Add `--zap` to also delete its presets, log and preferences.
